Política de Privacidad

Binance Pro Trading AI Assistant
Última actualización: 24 de agosto de 2026

Esta Política de Privacidad describe el tratamiento, almacenamiento y protección de datos aplicados por la extensión de Google Chrome Binance Pro Trading AI Assistant (en adelante, "la Extensión").

Declaración de Privacidad Principal: Binance Pro Trading AI Assistant opera de forma 100% local en el navegador del usuario. No recopilamos, no almacenamos en servidores externos, no rastreamos ni vendemos ningún tipo de información personal, datos de navegación ni credenciales financieras.

1. Recopilación y Uso de Datos de Usuario

La Extensión está diseñada bajo el principio de privacidad por diseño:

  • Sin información de identificación personal (PII): No se recopilan nombres, correos electrónicos, números de teléfono, direcciones IP ni datos biométricos.
  • Almacenamiento 100% Local: Todas las configuraciones operativas (capital asignado, preferencias de Stop Loss, Take Profit, Trailing Stop y el historial de simulaciones) se guardan única y exclusivamente en el almacenamiento local del dispositivo del usuario mediante la API oficial chrome.storage.local.
  • Sin Servidores de Telemetría: El desarrollador no opera servidores propios de análisis ni telemetría para monitorear el comportamiento de los usuarios.

2. Justificación de Permisos Declarados

La Extensión solicita únicamente los permisos indispensables para cumplir con su propósito:

  • storage: Permite guardar de manera local y persistente en el navegador las preferencias de riesgo, el capital configurado y el registro de operaciones.
  • notifications: Utilizado para emitir alertas de escritorio locales cuando una posición abierta alcanza sus objetivos técnicos de Take Profit, Stop Loss o activación de Break-Even.
  • alarms: Permite programar comprobaciones periódicas en segundo plano para evaluar el tiempo de inactividad de las operaciones en curso.
  • host_permissions (api.binance.com, stream.binance.com, api.groq.com): Permite la comunicación cifrada directa entre el navegador del usuario y los servidores públicos de Binance para la transmisión de precios en tiempo real por WebSockets (<50ms) y con la API de Groq AI para análisis cuantitativo cuando el usuario lo solicita explícitamente.

3. Seguridad de las Claves de API

Si el usuario decide configurar claves de API para operar en modo real en Binance Spot o para el oráculo de IA:

  • Dichas claves se almacenan localmente en el navegador y nunca se transmiten a ningún servidor que no sean los endpoints oficiales de Binance (api.binance.com) o Groq (api.groq.com).
  • La Extensión solo requiere permisos de lectura y trading spot; nunca solicita ni requiere permisos de retiro de fondos.

4. Ausencia de Código Remoto

En cumplimiento con las Políticas del Programa para Desarrolladores de Chrome Web Store (Manifest V3), todo el código ejecutable de la Extensión se encuentra empaquetado de forma local dentro del archivo de la extensión, sin cargar scripts remotos dinámicos.

5. Descargo de Responsabilidad Financiera

La Extensión es una herramienta de asistencia visual, analítica y matemática. No proporciona asesoramiento financiero ni garantiza rendimientos económicos. Todas las decisiones de inversión y la gestión de riesgo son responsabilidad exclusiva del usuario.

6. Contacto y Soporte

Si tienes preguntas o inquietudes sobre esta Política de Privacidad, puedes ponerte en contacto a través de la página del repositorio oficial del proyecto en GitHub.
